Project Title: MyShell – A Linux-Inspired Graphical Shell Environment
1. Project Overview
MyShell is a Linux-inspired graphical shell application developed using Python and Tkinter. It provides a graphical interface through which users can execute Linux commands and interact with the Ubuntu environment using Windows Subsystem for Linux (WSL 2).
The application combines command execution, file management, text editing, process management, and system information into a single desktop environment.
The project demonstrates important operating system concepts, including process execution, command interpretation, input/output handling, file operations, and concurrency.
2. Problem Statement
Traditional command-line interfaces require users to interact with the operating system through text-based commands. Although powerful, these interfaces can be difficult for beginners to understand and use, particularly when learning operating system concepts such as process management, file handling, and command execution.
Furthermore, understanding how commands interact with the operating system requires practical exposure to processes, input/output streams, and system resources.
Therefore, there is a need for a simple graphical environment that provides command-line functionality while allowing users to interact with files, processes, and system information through an accessible interface.
MyShell addresses this problem by providing a graphical shell environment that integrates Linux command execution with essential system-management features.
3. Aim of the Project
The main aim of MyShell is to develop a Linux-inspired graphical shell environment using Python and Tkinter that enables users to execute Linux commands and explore fundamental operating system functionalities through a simple graphical interface.
4. Objectives
•	To develop a graphical terminal interface using Python and Tkinter.
•	To execute Linux commands through Ubuntu using WSL 2.
•	To implement built-in shell commands such as cd, pwd, history, and clear.
•	To maintain command history for repeated access.
•	To provide a graphical file manager for browsing and managing Linux files.
•	To develop a basic text editor for creating, opening, and modifying files.
•	To display running Linux processes and provide process termination functionality.
•	To display system information, including memory and disk usage.
•	To demonstrate operating system concepts such as process execution, standard input/output, and concurrency.

6. Main Modules
6.1 Terminal Module
Provides a graphical command interface for entering and executing Linux commands. It displays command output, errors, and exit codes.
6.2 Shell Engine Module
Handles built-in commands, maintains the current working directory, manages command history, and coordinates external command execution.
6.3 WSL Interface Module
Connects the Windows-based Python application to Ubuntu WSL 2 using subprocess execution.
6.4 File Manager Module
Allows users to browse Linux directories, create files and folders, rename items, and delete selected files or directories.
6.5 Text Editor Module
Provides basic text-file operations, including opening, editing, and saving files inside the Linux environment.
6.6 Process Manager Module
Displays Linux process information such as process ID, username, state, and command. It also supports terminating selected processes.
6.7 System Monitor Module
Displays Linux system information, including uptime, memory usage, and disk usage.
7. Operating System Concepts Demonstrated
•	Process Management: Execution and management of external Linux processes.
•	Parent and Child Processes: Understanding how applications launch external programs.
•	Standard Input and Output: Capturing standard output and standard error from executed commands.
•	Exit Status: Identifying successful and unsuccessful command execution.
•	Inter-Process Communication: Using pipelines to pass output between commands through Bash.
•	File System Management: Creating, reading, modifying, and deleting files.
•	Concurrency: Using background threads to prevent the graphical interface from freezing.
•	Command Interpretation: Handling built-in commands and forwarding external commands to the Linux environment.
8. Scope of the Project
MyShell focuses on providing a basic graphical environment for Linux command execution and essential system-management operations.
The application is designed primarily for educational purposes, particularly for students learning operating system concepts and Linux fundamentals.
It is a user-space application and does not implement or replace the Linux kernel or a complete Linux operating system.
9. Expected Outcome
The expected outcome is a functional desktop application that provides a graphical terminal connected to Ubuntu WSL 2, along with file management, text editing, process management, and basic system monitoring capabilities.
The project helps users understand the relationship between command execution, processes, file systems, and operating system resources through practical implementation.
10. Future Enhancements

•	Add background job management and process tracking.

•	Improve pipeline and input/output redirection handling.
•	Add syntax highlighting and advanced text-editing features.

11. Conclusion
MyShell provides a practical demonstration of fundamental operating system concepts through a Python-based graphical shell environment. By integrating Windows, Python, Tkinter, and Ubuntu WSL 2, the project combines command execution with essential file and process management features.
The project serves as an educational platform for understanding how user applications interact with operating system services and manage external processes.
